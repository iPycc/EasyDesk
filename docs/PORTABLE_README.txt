EasyDesk Windows 客户端
=======================

运行：双击 EasyDesk.exe。

请保留发布目录内的媒体库、Qt DLL、platforms、imageformats、styles 和 MSVC 运行库；本包不是单文件程序。

当前能力
--------
- 读取本机 Windows 设备信息。
- 保存用户添加的设备与界面设置。
- 显示本机设备 ID、8 位协助码和真实连接状态。
- 提供设备、远程协助与设置界面。
- 支持与信令服务协商会话，桌面观看链路已完成同机联调。

当前限制
--------
- 该版本仍在开发；观看模式需要双方连接同一可达的信令服务，真实双机和跨网尚未完成验收。
- 键鼠控制入口暂不可用，文件传输尚未实现。
- 屏幕切换、画质与帧率设置尚未开放。
- 不包含示例设备、合成远程桌面或模拟文件进度。

数据目录
--------
默认：%LOCALAPPDATA%\EasyDesk\EasyDesk\settings.ini

设置 EASYDESK_DATA_DIR 可指定独立数据目录。旧 preview.ini 仅用于一次兼容迁移。
