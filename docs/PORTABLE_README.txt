EasyDesk 1.0.0 · 前端预览（Windows x64）

解压整个 EasyDesk 文件夹，双击 EasyDesk.exe。
请保留同目录的 DLL、platforms、styles、imageformats、licenses 和 qt.conf。
无需安装 Qt、Python、Rust，也无需启动后端服务。

默认窗口：920 × 680 DIP；支持拖动、缩放和最小化，不提供最大化。
界面：C++17 + Qt 5.15.12 Widgets + QSS + Svg，支持浅色与深色主题。
浅色采用淡蓝灰的白色底板；深色保持 Windows 中性灰黑，不使用蓝灰色。
字体：Windows 自带的微软雅黑 UI / 微软雅黑，缺失时使用系统界面字体。
输入、确认、设备详情和文件队列采用当前窗口内的遮罩模态面板；远程桌面保留独立窗口。图标使用 SVG。
通知出现在右上角。最小化动画遵循 Windows 系统动画设置。
控件与导航无选中外框，本机设备区有固定边框；下拉与三点菜单采用统一圆角样式。
二级导航向右缩进，子项图标与一级项文字对齐，选中背景保持整行。
独立桌面窗口的信号详情和操作菜单均在顶部，不再显示底部操作栏。
信号详情中的延迟、双端 IP、帧率、丢包与 UDP/P2P 状态均为模拟数据。
远程窗口与主界面各有任务栏入口，可以分别最小化、还原。
全屏隐藏本地标题栏和边距，仅显示模拟桌面；F11 / Esc 返回原窗口尺寸与位置。

可以体验：设备列表、搜索、收藏、添加与备注、离线状态、
模拟远程连接、独立桌面窗口、文件队列、四个设置标签页。

本机名称、系统、主板、处理器和网卡 MAC 来自 Windows；显示在顶部原有设备卡及全部设备中。
远程设备、临时码、视频画面、连接状态与文件进度均为模拟。
本机重命名只保存应用内显示名称，不修改系统电脑名。
快捷启动默认为空，可保存配置，实际远程执行尚未接入。
程序不会连接真实设备、读取真实桌面、发送文件或注入键鼠。
添加和修改的设备在重新启动后恢复为示例数据。
设置保存在当前用户 AppData/Local/EasyDesk/EasyDesk/preview.ini。

快捷键：
Ctrl+F                   搜索设备
F11                      切换演示桌面的全屏
Esc                      退出演示全屏 / 关闭演示桌面
Ctrl+Alt+Shift+F12       演示会话菜单
Ctrl+Alt+Shift+F11       停止演示会话

可在“开始远程”中点击“使用示例设备”体验连接表单。
演示表单接受任意 8 位数字示例码，不做真实身份认证。

当前仅在本机 Windows 11 x64 进行验证。
Windows 10 与干净系统的独立验收尚未执行。
